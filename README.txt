VortexMC website
================
Static VortexMC recreation based on the publicly visible AppleMC site structure.

Upload all files/folders to your web host.
- index.html = home
- rules.html = rules
- vote.html = vote rewards
- forum.html = forum entry
- store.html = store
- register.html = registration
- style.css = styling
- assets/logo.png = supplied VortexMC logo

Brand changes requested:
- AppleMC -> VortexMC
- AppleMC logo -> supplied VortexMC logo
- Discord -> https://discord.gg/nbNMExf4yg

The public AppleMC site currently exposes Home, Rules, Vote Rewards, Interactive Map, Store and Forum navigation. The package mirrors that visible structure.
